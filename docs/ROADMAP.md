# Public Roadmap

The Starter edition stays intentionally small and useful. Planned improvements are driven by reproducible lab validation rather than the number of scripts.

- Structured output (TextFSM/Genie where reliable)
- Additional vendor command maps
- Better inventory validation
- Optional SSH key authentication examples
- Example CI checks for network configuration repositories
- Compatibility matrix populated from real devices and lab images

Paid editions extend into compliance, pre/post change validation, guarded configuration deployment, NETCONF, and reusable templating workflows.
